# Proyecto Linamar

## Cambios realizados v2.0 20/03/25

**Modulos**  

- Authentication

Front
Se agrego el envío de Authentication: token, en cada petición que se realice de tipo GET o POST.
También se agregó una validación, el cual redirige al login en caso de que backend devuelve código -2 (no autorizado) en la petición.

Backend
Se corrigió metodos de autenticación y validación de token.
Se agregó validación de token en los metodos de listado y registro en demas controladores (detalles y distritosLima).

- Login

FrontEnd
Se agregó pantalla de login con diseño basico.

- SweetAlert

Front
Se actualizó librería de SweetAlert a la versión 2 y se actualizó la llamada al método de Swal con la sintaxis de la versión 2.
