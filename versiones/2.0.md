# Proyecto Linamar

## Cambios realizados v2.0 - 20/03/25

### **Módulos**

#### **Authentication**

**Frontend**  
- Se agregó el envío de **Authentication: token** en cada petición **GET** o **POST**.  
- Se implementó una validación que redirige al **login** en caso de que el backend devuelva el código **-2 (no autorizado)** en la petición.  

**Backend**  
- Se corrigieron los métodos de autenticación y validación de tokens.  
- Se agregó validación de token en los métodos de **listado** y **registro** en los demás controladores (**detalles** y **distritosLima**).  

#### **Login**

**Frontend**  
- Se agregó una pantalla de **login** con un diseño básico.  

#### **SweetAlert**

**Frontend**  
- Se actualizó la librería **SweetAlert** a la versión **2**.  
- Se modificó la llamada al método de `Swal` para adaptarse a la sintaxis de la versión 2.
